# 构建

构建需要 mdBook，可以从 crates.io 安装：

```sh
cargo install mdbook
```

将安装目录 `~/.cargo/bin` 加入系统 PATH 后，在本地副本的根目录运行：

```sh
mdbook build
```

---

如果你愿意，也可以使用
[GitBook](https://github.com/GitbookIO/gitbook)，但 GitBook 可用于
构建本项目。不过 GitBook 未获官方支持，因此兼容性不确定，也不构成本项目的支持范围。
