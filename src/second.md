# 一个还行的单向链表栈

在上一章里，我们写出了一个最小可用的单向链表栈。不过有几个设计决策
让它有点糟。我们来让它不那么糟。在这个过程中，我们会：

* 把轮子拆掉（别自己造了）
* 让我们的链表能够处理任意元素类型
* 加上查看功能
* 让我们的链表可以迭代

在这个过程中，我们会学到

* Option 的进阶用法
* 泛型（generics）
* 生命周期（lifetime）
* 迭代器（Iterator）

让我们添加一个名为`second.rs`的新文件：

```rust ,ignore
// in lib.rs

pub mod first;
pub mod second;
```

然后把`first.rs`里的所有内容复制进去。
